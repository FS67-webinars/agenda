# Agenda

Учебная афиша событий для группы FS-67 курса FullStack Tel-Ran. Страница использует HTML, CSS и локальный Bootstrap 5.3.8.

1. Откройте папку `agenda` в VS Code.
2. Откройте `index.html` в браузере из файлового менеджера.
3. Сохраняйте изменения в редакторе и обновляйте страницу в браузере.
